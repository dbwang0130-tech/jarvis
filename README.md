# jarvis — 个人助理

一个终端同时管理 **日程（org-mode）** 和 **邮箱**，内置一个能直接动手改文件和收发邮件的私人助理。

```
 jarvis
──────────────────────────────────────────────────────────────────────────
今天 2026-09-14 周一 · 3 件已排期 · 1 项今天到期
  工作:      14:00-16:00 NEXT [#A] 把 jarvis 用起来  :jarvis:
──────────────────────────────────────────────────────────────────────────
> 帮我整理今天的邮件，并把里面提到的会议排进日程
● 同步邮件 {}
● 整理邮件 {}
  ⎿  已标注 12 封…
● 新建条目 {title=…}
● 我整理完了：3 封要紧，5 封广告可以清掉…
```

## 安装

```sh
make install    # 编译出 jarvis 并装到 ~/.local/bin/
```

之后直接敲 `jarvis`。配置不用离开界面——所有配置都在里面用 `/` 命令完成。

## 快速开始

```sh
jarvis
```

启动就是助理，输入框已聚焦。第一次用敲一句：

```
/setup
```

六步走完就配好了——模型、日程文件、邮箱、账本、自动档、后台提醒。每步直接回车就跳过（保持原样），esc 随时退出，前面存下的不会回滚。随时可以再跑一遍：填的还是原值就什么都不动，只改你想改的那几项。

也可以单独改某一项：

```
/login sk-...        # 只设模型密钥（不回显）
/provider qwen       # 换服务商，支持 deepseek / qwen / kimi / minimax / zhipu / doubao / spark / baichuan / ollama
/mail                # 加一个邮箱账号
/files ~/org         # 换 org 文件或目录（目录不存在会自动创建）
```

没配置 org 文件时，会自动创建 `~/org/inbox.org`。

## 秘书能做什么

一个秘书，三套技能（Skill），还可以继续加：

- **日程**：查日程/待办/空档，安排时间、改截止、改状态和优先级、设循环任务、新建/删除条目
- **邮件**：增量同步（只拉新邮件）、triage 分类、写简报、把邮件里的时间点排进日程、清理广告、起草回信/新邮件
- **记账**：ledger-cli 纯文本格式，复式记账、查余额、看流水（`/ledger` 设置账本文件，未配置时默认用 `~/finance/ledger.dat` 并自动创建）

有风险的动作会停下来等你确认。自动档用 `/auto` 切换：

| 档位 | 清理邮件 | 发信 |
|---|---|---|
| 逐项确认 | 问 | 问 |
| 自动整理 | 直接做 | 问 |
| 全自动 | 直接做 | 直接做 |

发出去的信收不回来，开「全自动」前想清楚。确认框里选「以后不用问」也会把档位提上去。

## 界面

整块屏幕由 jarvis 自己画：内容在上，输入框钉在最底下不动。界面上的话分三层——`> ` 是你说的，`⏺ ` 是秘书说的和它调的工具，缩进两格的 `⎿ ` 是工具结果、`· ` 是程序回执。滚轮或 PageUp/PageDown 往回翻历史，输入框始终在原地。退出后会把这一趟的内容回放到终端里，照样能翻能复制。

```
╭──────────────────────────────────────────────────────────╮
│ > 帮我整理今天的邮件，并把里面提到的会议排进日程          │
╰──────────────────────────────────────────────────────────╯
  ● 秘书 · deepseek-chat · 上下文 12% · 自动整理 · tab 切视图
```

`tab` / `shift+tab` 轮换五个视图。视图是整屏换掉，不往对话里灌东西——切来切去聊天记录还是原样：

| 视图 | 内容 |
|---|---|
| 秘书 | 对话本身，只有这个视图有输入框 |
| 日程 | 按天展开的计划、截止、事件与逾期 |
| 待办 | 全部未完成条目 |
| 邮件 | 本次同步到的邮件清单 |
| 财务 | 净资产概览与最近流水 |

在别的视图里随便敲个字就回到秘书视图接着输入（`i` 只回去、不落字）。

| 键 | 作用 |
|---|---|
| `ctrl+r` | 重读 org 文件并刷新当前视图 |
| `esc` / `ctrl+c` | 打断秘书；确认框里是取消 |
| 滚轮 / `PageUp` `PageDown` | 往回翻历史，输入框不动 |
| 按住 `option` 拖 | 选择文字（滚轮和拖选只能要一个，见下） |
| `alt+回车` | 换行（回车是提交），输入框跟着长高 |
| `tab` | 正在打 `/` 命令时是补全，否则切视图 |
| `ctrl+l` | 清掉翻得到的历史 |

**滚轮和拖选复制只能要一个**：收滚轮事件就得开鼠标上报，终端原生的拖选随之被拦掉。默认给滚轮，要选文字按住 `option`（或 `shift`）拖就能绕过；嫌麻烦就 `/mouse off` 换成拖选优先，翻历史改用 `PageUp`/`PageDown`。这个选择会记进配置。另外退出后这一趟的内容会回放到终端里，在那儿可以随便选随便复制。

打 `/` 的时候候选命令会列在输入框上面，`tab` 补全。粘一段多行文本进来会整段收下，不会被拆成好几条发出去。秘书干活时输入框照常留着，可以接着打字：回车会把这句话排进队列，等它忙完自动接着办（状态栏会显示排了几句）。打断时那句还没得到答复的话会退回输入框，改一改就能重发。

行编辑是 readline 那一套：

| 键 | 作用 |
|---|---|
| `↑` `↓` / `ctrl+p` `ctrl+n` | 翻输入历史 |
| `←` `→` / `ctrl+b` `ctrl+f` | 移动光标 |
| `alt+b` `alt+f` | 按词移动 |
| `ctrl+a` / `ctrl+e` | 行首 / 行尾 |
| `ctrl+k` / `ctrl+u` | 删到行尾 / 删到行首 |
| `ctrl+w` / `alt+d` | 删前一个词 / 删后一个词 |
| `ctrl+y` | 把刚删掉的粘回来 |
| `ctrl+t` | 把光标前两个字掉个个儿 |
| `ctrl+d` | 删光标处那个字；行是空的就退出 |

秘书回复里的 markdown 会直接渲染：标题、列表、引用、代码块、表格，以及 **粗体**、`行内代码`、链接（认得 OSC 8 的终端里可以直接点）。

有风险的动作会弹确认框，`↑↓` 选、回车确认，也可以直接按编号：

```
╭──────────────────────────────────────────────────────────╮
│ 清理 12 封广告                                           │
│                                                          │
│ 要执行吗？                                               │
│ ❯ 1. 确认                                                │
│   2. 确认，以后这类整理不用问我                          │
│   3. 取消，我另有交代                                    │
╰──────────────────────────────────────────────────────────╯
```

选「以后不用问」就等于把自动档提上去：可逆动作提到「自动整理」，发信提到「全自动」。发出去的信收不回来，想清楚再选。

## 配置

配置文件在 `~/.config/jarvis/config.json`（权限 `600`），一般用 `/` 命令改就行，也可以直接编辑：

```json
{
  "files": ["~/org"],
  "inbox": "~/org/inbox.org",
  "work_hours": { "start": 9, "end": 22 },
  "agent": { "provider": "deepseek", "temperature": 0.3, "auto_compact": true },
  "ledger_file": "~/finance/ledger.dat",
  "profile": { "interests": "我是研究生，导师是王老师，最近在写开题报告……" },
  "behavior": { "auto_confirm": "clean" },
  "accounts": [
    { "name": "gmail", "host": "imap.gmail.com", "user": "you@gmail.com" }
  ]
}
```

邮箱密码和模型密钥一律存 macOS 钥匙串，配置文件里不落明文（也可用 `password_cmd` / `api_key_cmd` 从 1Password、pass 等取）。

## 开发

```sh
make test     # go test ./...
make fmt      # gofmt 整个项目
make build    # 只编译不安装
```

架构上，秘书内核与业务解耦：

```
internal/agent/    秘书内核：模型客户端 + 工具循环 + 风险确认 + 上下文压缩
  tool.go          Tool / Skill 接口，新增场景实现 Skill 即可接入
internal/orgtools/ 日程技能（org 解析、agenda、改写工具）
internal/mail/     邮件技能（会话、同步、triage、起草、清理、发送）
internal/ledger/   记账技能（ledger-cli 纯文本解析、余额、追加交易）
internal/org/      org-mode 解析与写回
internal/agenda/   把条目投影到日期上的 agenda 引擎
internal/mailbox/  IMAP/SMTP
internal/config/   统一配置 + 钥匙串
internal/chat/     界面：整屏自绘、输入框、视图切换、确认框
internal/browser/  Chrome 自动化技能
internal/memory/   长期记忆技能
internal/workflow/ 命名工作流技能
internal/session/  会话历史持久化
```

拉依赖要绕开代理：

```sh
unset HTTP_PROXY HTTPS_PROXY http_proxy https_proxy
export GOPROXY=https://goproxy.cn,direct GOSUMDB=off
```
